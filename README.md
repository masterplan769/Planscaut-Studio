# Planscaut Studio

**Planscaut Studio** is a lightweight Python-based code editor and development environment designed to provide a simple, modern workspace for writing, editing, and running code.

## ✨ Features

* 📝 Code editor with tabs
* 📂 File and folder navigation
* 💾 Open and save files
* 🔍 Find/search functionality
* ▶️ Run code directly from the editor
* 🛑 Stop running processes
* 🌙 Dark-themed interface
* 📑 Multiple open files
* ⚡ Lightweight and fast
* 💻 Built with Python and PyQt
* 🔔 Unsaved-changes protection when closing
* 🎨 Custom Qt stylesheet and UI

## 📋 Requirements

Before running Planscaut Studio, make sure you have:

* Python 3.9 or newer
* PyQt5

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/masterplan769/planscaut-studio.git
```

Enter the project directory:

```bash
cd planscaut-studio
```

Install the required dependency:

```bash
pip install PyQt5
```

## 🚀 Running Planscaut Studio

Run the main Python file:

```bash
python planscaut_studio.py
```

Planscaut Studio should open in a new window.

## 🎯 Purpose

Planscaut Studio was created as a personal development project with the goal of building a simple code editor without relying on a large existing IDE.

The project focuses on:

* Simplicity
* Performance
* A clean interface
* Useful developer features
* Learning how editors and desktop applications work
